# 乘法保卫战 · 植物大战僵尸九九乘法表 🌻🧟

给小学生玩的九九乘法表学习游戏：僵尸举着乘法算式进攻草坪，答对题目豌豆射手才能发射豌豆保卫家园！

## 玩法

- **🎓 乘法课堂**：豌豆点阵直观理解「乘法 = 重复相加」，逐句学会 2-9 口诀，含自测模式
- **⚔️ 保卫草坪**：5 波塔防闯关，答对击杀僵尸、答错僵尸加速，可自选练习范围，小推车救急
- **📕 错题本**：答错口诀自动收集，连对 3 次「毕业」，间隔重复攻克薄弱点
- **📊 九九乘法表**：45 句口诀全景地图，颜色标记掌握进度

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS，纯前端，练习数据保存在浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev
```

## 部署

仓库包含 `render.yaml`，可在 Render 一键创建静态站点（构建 `npm run build`，发布目录 `dist`）。
